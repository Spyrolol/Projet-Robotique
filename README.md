# Projet-Robotique
Projet Robotique – Navigation autonome

• Développement d’un robot capable de naviguer de manière autonome dans un circuit prédéfini.

• Programmation de la logique de déplacement, détection d’obstacles et prise de décision en temps réel.

• Utilisation de C++.

• Tests fonctionnels pour optimiser le parcours et réduire les erreurs de navigation.
